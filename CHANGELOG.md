# Treehouse Arcade changelog

Newest first. Each entry is dated (YYYY-MM-DD).

## 2026-11-11 · version 2026-11-11c
- New phone-upload bundle (`treehouse-arcade-upload.zip`): all files side by side, no folders, so they can be uploaded to GitHub from a phone in one go. Built by `tools/build-flat.py`.
- Hub: grass strip along the bottom now shows.

## 2026-11-11 · version 2026-11-11b
- Added dates everywhere: a "Last updated" line at the top of each file, an "Updated" date on each game tile and on the Snack Snakes home screen, and the arcade version at the bottom of the hub.
- Added this changelog.

## 2026-11-11 · version 2026-11-11a
- New: Treehouse Arcade hub, installable on iPad as one home-screen icon, works offline after the first visit.
- Snack Snakes moved into the arcade:
  - Final showdown is now against the biggest computer snake of the round (no saved high-score boss).
  - Computer snakes have mixed skill levels; the best one gets weaker after losses (faster on a losing streak) and stronger after wins.
  - Rounds are 30 seconds or 1 minute.
  - Dress-up room with picture tabs: Color, Pattern, Head, Face, Tail (hearts, stars, scales, glitter, tiara, flower crown, unicorn horn, dragon horns, kitty ears, eyelashes, star eyes, sunglasses, tail bow, rattle, sparkles and more). Crown unlocks after 3 showdown wins.
  - House button returns to the arcade.

## 2026-11-10
- First version of Snack Snakes (single page in chat): finger steering, tail biting, zoom-out as you grow, boss showdown, shop upgrades.
